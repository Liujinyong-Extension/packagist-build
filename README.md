# packagist-build


#### 好烦每次开发扩展包都需要重写一堆文件



## 【使用方法】

```shell
  composer global require liujinyong/packagist-build
 
 #创建包的命令
 packagist-build create 
 
# windows如果命令不好使可能的原因如下

# 添加 Composer 全局 bin 目录到 PATH（Windows）
# 1. 打开环境变量设置
# 2. 在 PATH 中添加：
#    C:\Users\你的用户名\AppData\Roaming\Composer\vendor\bin
# 或
#    %APPDATA%\Composer\vendor\bin

# 重新打开命令行窗口使 PATH 生效
 
```
